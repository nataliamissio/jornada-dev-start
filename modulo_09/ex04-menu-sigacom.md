# Exercicio 4 - Menu no SIGACOM (bonus)

Configurar no SIGACFG > Menu do Sistema (modulo Compras):

## Estrutura

Cadastros

- Contatos -> USER FUNCTION STTIP003
- Interacoes (todas) -> USER FUNCTION STTIP004B

## Observacoes

1. STTIP004B deve listar SZ2 sem filtro por contato.
2. STTIP004 (sem B) e a versao filtrada usada pelo botao Interacoes dentro de Contatos.
3. Compilar antes os fontes da pasta do ex02 para garantir que as funcoes existam no menu.
